# 验证说明

基础原包：作者通过 Modrinth 发布的 BSL 10.1.8，版本 ID `Y68yiql9`。下载后核对平台提供的 SHA-512，并确认五个魔改目标文件与开发用原始备份逐字节相同。

## 已通过的检查

- 纯汉化及魔改语言文件无重复语言键，完整包含原版 895 个语言键；366／368 个选项均有中文说明。
- 新增画质配置、页面与滑块引用合法，四档性能参数覆盖集合相同。
- 对称 5 点阴影采样的索引范围、对称性及平均亮度归一化；9 点仍使用原版采样布局。
- 运行用 `.properties` 文件全为 ASCII，避免 Iris 的 properties 预处理编码问题。
- Windows PowerShell 5.1 实际运行魔改工具，从官方 ZIP 生成修改包；目标文件逐项与修复版比较。
- ZIP 归档完整性、语言覆盖目标、最外层结构检查。

## 游戏运行验证

测试环境已识别为 GTX 1070 Ti、Minecraft 26.3、Iris 1.11.7。初版日志中的 `Properties pre-processing failed / Bad token` 导致程序开关失效，并触发 `shadowcomp` 的 `lightColorsRGB`／`tintColorsRGB` 未定义错误。补丁已修正配置编码。

当前游戏重载结果尚待确认。静态检查与本地生成成功不等于全部预设、维度、模组组合已完成运行验证。没有受控场景下的 FPS 对比结果，不承诺具体帧率。

## 安装工具的保护措施

先检查全部基础文件，再应用差量；验证生成后的文件哈希；保留输入原版 ZIP；拒绝覆盖已存在的输出包。失败时只清理工具创建的临时文件，不修改输入原版或存档。
