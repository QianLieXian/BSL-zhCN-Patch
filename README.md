# BSL 10.1.8 简体中文覆盖补丁

为 BSL 光影的游戏内设置提供简体中文名称、档位、悬停说明和调参提示。提供普通汉化与可选的 GTX 1070 Ti 优化魔改补丁。

**先下载官方原版光影，再安装本仓库的补丁。本仓库和 Releases 不提供完整 BSL 光影包。**

原光影：**BSL Shaders**；原作者：**Capt Tatsu**。这是非官方补丁，未经原作者背书，请保留原作者署名。

## 纯汉化：下载原版后覆盖

1. 从上面的官网入口下载 **BSL 10.1.8**，保留原版 ZIP 作为备份。
2. 解压原版到一个独立文件夹，例如 `BSL_v10.1.8_zhCN`。确认里面是 `shaders` 文件夹。
3. 解压纯汉化补丁，把其中的 **`shaders` 文件夹**复制到上一步的光影文件夹中，选择合并／覆盖。
4. 最终结构应为 `BSL_v10.1.8_zhCN/shaders/lang/zh_CN.lang`，不要多套一层 `shaders/shaders`。
5. 把整个 `BSL_v10.1.8_zhCN` 文件夹放进你正在使用的游戏实例的 `shaderpacks` 中，或将它内部的 `shaders` 文件夹重新压成 ZIP 后放入。
6. 游戏语言选择“简体中文”，加载这个包，进入光影设置。鼠标停留在选项上即可阅读中文说明。

也可以用压缩软件打开原版 ZIP，把补丁中的 `shaders/lang/zh_CN.lang` 放到 ZIP 内的相同位置。覆盖前先复制原版 ZIP，不要丢失原版。

纯汉化有 **1,058 个语言条目，366 个设置选项均有中文说明**。完整覆盖原版 895 个语言键，并补充原版没有说明的颜色与天空参数。修改纯汉化文件不会启用高级材质、彩光或任何优化预设。

## 优化魔改：在原包上生成并覆盖改动

为了避免重新分发原光影代码，发布包只包含中文文件、最小改动清单和补丁工具。完整修改包由工具在本地基于用户下载的官方原包生成。

**Windows 安装步骤：**

1. 下载官方 **BSL 10.1.8** 原版 ZIP。
2. 下载并解压 `BSL_10.1.8_zhCN_1070Ti_ModPatch_v0.1.0.zip`，不要只从压缩软件中单独运行一个文件。
3. 双击 **`应用优化魔改.cmd`**，在文件选择窗口中选择官方原版 ZIP。
4. 工具先验证基础文件，再覆盖生成汉化和优化代码，最后在原 ZIP 旁创建 **`BSL_v10.1.8_zhCN_1070Ti.zip`**。原版 ZIP 保留不变；若输出文件已存在，会停止而不覆盖。
5. 把新生成的 ZIP 放进游戏实例的 `shaderpacks` 文件夹，游戏中选择这个新包。
6. 游戏语言选“简体中文”；在光影设置里先选 **「1070 Ti｜保真均衡（推荐）」**。再到 **「性能微调（1070 Ti）」** 自己调整。

当前补丁工具适用于 Windows PowerShell 5.1 及以上，不需要 Python 或额外解压软件。其他系统可使用纯汉化覆盖包；当前不提供其他系统的魔改安装工具。

## 四档魔改预设

| 预设 | 阴影贴图／半径 | 反射步数／柔和阴影采样 | 主要取舍 |
|---|---|---|---|
| 保真均衡（推荐） | 2048／192 方块 | 24／9 点 | 保留现代 AO、水面视差、体积云、光柱、完整反射和 TAA；远处投影更早淡出，部分细小反射可能漏检 |
| 高帧流畅 | 1536／128 方块 | 20／5 点 | 保留主要光影，采用经典 AO、关闭水面视差、快速远景反射；细小阴影和反射精度有所下降 |
| 近景彩光 | 1536／128 方块 | 20／5 点 | 开启 128 范围体素彩光、垂直范围减半，关闭彩光体积雾；比普通高帧档更耗性能，**需要支持该功能的 Iris** |
| PBR 近景 | 1536／128 方块 | 24／5 点 | 启用 labPBR，视差 32 采样／16 方块，关闭材质自阴影与粗糙反射；需要匹配的 PBR 资源包 |

魔改包有 **1,073 个语言条目，368 个设置选项均有中文说明**。新增反射最大步数 16／20／24／30，以及对称的 5 点／原版 9 点阴影滤波。5 点滤波会同时调整普通与彩色阴影的归一化，避免改变平均亮度。

四档均保留体积云默认厚度与细节、体积光柱、泛光和完整水面反射；关闭景深、运动模糊等额外效果。部分关闭项原版默认就已关闭，不能把这些开关计为相对默认包的帧率收益。

四档管理同一组选项，可以相互切换。切回普通档会关闭 PBR 或体素彩光，避免留下额外开销。选择预设会覆盖它管理的设置，手动调节后显示“自定义”属正常现象。要完整恢复原包默认设置，请使用游戏里的“重置”或重新选择保留的官方原包。

## 已知限制与报错修复

- 修复了初版把中文直接写进 `.properties` 注释导致 Iris 预处理 `Bad token`、继而错误编译 `shadowcomp` 的问题。**运行用 properties 文件保持 ASCII；中文说明保留在语言文件，配置中的中文注释使用 Unicode 转义。**
- 反射步数减少可能漏掉细小或复杂的反射；遇到反射缺失恢复 30 步。
- 5 点柔和阴影边缘可能更粗或闪烁；遇到问题恢复 9 点，TAA 只能缓解部分瑕疵。
- 近景彩光档需要原包要求的计算着色器和自定义图像功能；不要在 OptiFine 中使用此档。
- PBR 材质格式必须与资源包匹配。普通资源包建议用保真或高帧档。
- OptiFine 用户启用内置 FXAA/TAA 时，按原包说明关闭光影主菜单中的外部抗锯齿。
- 不修改游戏存档。错误版本、已有其他代码魔改或重复输出路径会停止安装；保留原版即可恢复。

发布前验证范围见 [验证说明](docs/VALIDATION.md)。性能受分辨率、视距、CPU、资源包与场景影响；未提供受控场景下的实测 FPS 对比。
